# NoType 0.4.0

NoType 0.4.0 replaces the bundled Whisper path with smaller on-device engines, adds configurable
shortcuts and diagnostics, and introduces a compact voice overlay for recording and delivery
feedback. Speech remains on the Mac.

## What's new in 0.4.0

- Qwen3-ASR 0.6B INT8 is the multilingual local engine and handles mixed Chinese-English speech.
- SenseVoice Small is available as an optional local engine for Chinese, Cantonese, English,
  Japanese, and Korean.
- Models download only when selected into the shared Hugging Face model directory and are managed
  from the menu bar.
- Dictation and recognition-mode shortcuts can be recorded, combined, or disabled independently.
- The Diagnostics menu shows local model preparation, readiness, and failure details.
- The optional bottom-center voice overlay shows a live recording waveform and compact delivery
  feedback. Completion and failure durations can be entered independently from 0 to 5 seconds.

## Download and install

1. Download `NoType-0.4.0-arm64.zip` and unzip it.
2. Move `NoType.app` to `/Applications`, replacing an older copy if present.
3. On first launch, Control-click the app and choose **Open** if macOS asks for confirmation.
4. Grant Microphone and Accessibility permissions when requested.

The archive does not contain speech models. NoType downloads the selected model from the official
sherpa-onnx release archive on first use and reuses it across app updates.

## Requirements

- Apple Silicon Mac (`arm64`)
- macOS 15.0 or newer
- Microphone permission for recording
- Accessibility permission for shortcuts, target capture, and text insertion
