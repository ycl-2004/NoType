# NoType 0.3.0

NoType 0.3.0 pairs a new Orbit-inspired YC app icon with faster first-use preparation and safer dictation edge-case handling.

## Highlights

- New microphone → waveform → document icon in the warm watercolor YC/Orbit visual system.
- Preloads the local WhisperKit model in the background after launch.
- Stops fallback transcription attempts once the current result is conclusive.
- Skips sub-0.3-second accidental recordings and empty transcripts without touching the clipboard.
- Deletes temporary recordings after every outcome and removes orphaned clips on launch.
- Protects the original text target so a completed transcript is copied instead of inserted into a different chat or document.
- Improves filler and hallucinated-sign-off cleanup while preserving ordinary repeated or conversational phrases.

## Install

1. Download `NoType-0.3.0-arm64.zip` and unzip it.
2. Move `NoType.app` to `/Applications`.
3. On first launch, Control-click the app and choose **Open**.
4. Grant Microphone and Accessibility permissions when requested.

The archive includes the WhisperKit `large-v3` Core ML model and tokenizer. No setup script, account, remote transcription service, or separate model download is required.

## Requirements

- Apple Silicon Mac
- macOS 15.0 or newer
- About 4 GB of free space during download and extraction
